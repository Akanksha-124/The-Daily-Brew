5. E-Commerce & Ordering Architecture

  • Shopping Bag Drawer:
    • Terminology: Strictly uses "Shopping Bag" to reinforce luxury positioning.

  • Checkout Experience:
    • Fulfilment Toggle: White-Glove Home Delivery vs. Storefront Pickup.
    • Guest validation: Full Name, 10-digit Phone, Email, Address, and 6-digit PIN code.
    • Transparent Demo Payment options: UPI, Credit/Debit Card, Net Banking, and Cash on Delivery.
    • Zero hardcoded API secrets; architecture modularized for backend Razorpay webhook integration.
  • Order Confirmation & Tracking:
    • Unique order reference ID generation (e.g., TDB-984210).
    • Celebratory confetti burst.
    • Itemized manifest, guest contact, and financial receipt.
    • Simulated 4-stage tracking timeline: Order Placed → Preparing Your Order → Out for Delivery / Ready for Pickup → Delivered.
